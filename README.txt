# Number Guessing Game

My first C programming project, built after completing the first two weeks of [CS50x](https://cs50.harvard.edu/x/).

## About the Project

A simple command-line number guessing game written in C.

The computer generates a random number between **1 and 100**, and the player has to figure out what it is.

The game provides hints after each guess:
- **Too high:** Your guess is higher than the secret number.
- **Too low:** Your guess is lower than the secret number.
- **Correct:** You guessed it!

## Built With

- C
- CS50 Library

## Concepts Practiced

- Variables and data types
- User input and output
- Conditional statements (`if`, `else if`)
- `do-while` loops
- Comparison operators
- Random number generation
- Debugging and problem-solving

## How to Play

1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints.
4. Keep guessing until you find the secret number!

## Why I Built This

This is one of my first hands-on projects while learning programming through CS50x.

The goal was to practice the fundamentals of C by building something functional rather than just watching lectures.
